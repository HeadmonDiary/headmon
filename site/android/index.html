Version 4.0.1

Why this update was needed

Day details previously looked selected in the app but were not written to the diary until Save day or Save day context was pressed. That extra step was easy to miss—especially for day triggers—so Insights could be incomplete even though the day card appeared filled in.

Headmon 4.0.1 fixes that long-standing behavior:

  • Day triggers and medicines save as soon as they are selected or removed.
  • Dosage edits, stress-slider changes and notes save automatically after a short pause.
  • Pending day details are saved when you leave the editor, and the separate Save day button is no longer required.
  • The Android app can now tell you when a newer direct-download release is available, with a manual check under Settings → About Headmon.

Before installing

Protect your diary first.

If Headmon is already installed, do not uninstall it. Create a complete backup in a Files folder, then install the new APK over the existing app. Uninstalling removes local diary data and local-only backups.

First installation

Four steps on your Android device.

  1. Download the APK.Use the button above and open the completed download.
  2. Allow this source when Android asks.Enable “Allow from this source” for the browser or file app you used. This permission applies to that app, not to Headmon.
  3. Choose Install.Android may also show a Play Protect notice because the APK came from outside Google Play. Confirm only if the package came from this page or the linked Headmon GitHub release.
  4. Turn the source permission off again.After installation, return to the browser or file app’s “Install unknown apps” setting and disable it until the next update.

Updating Headmon

Install over the existing app.

Headmon checks this site for version information when the app opens, at most once every 24 hours. You can also use Settings → About Headmon → Check for updates. The check sends no diary content.

When an update is available, download it here and install it without uninstalling Headmon. Android accepts the update only when its package name and developer signing key match and its version is newer.

Troubleshooting

Android says “App not installed”

Do not uninstall the existing app. Confirm that you downloaded the newest official Headmon APK. A differently signed old build cannot be updated in place; create an external complete backup before changing installations.

The Install button is unavailable

Open Settings → Apps → Special app access → Install unknown apps, choose the browser or file app holding the APK, and temporarily allow that source. Menu names vary by device.

Play Protect shows a warning

Directly distributed apps can receive an extra warning. Check that the address is headmondiary.com or the official HeadmonDiary/headmon GitHub release before continuing.
