Independent support

Help with Headmon

Headmon is maintained as a small independent project. Reports are welcome, and protecting your diary comes first.

Contact

For a private question, email headmon@proton.me. For a reproducible bug or feature request that contains no private information, use GitHub Issues.

Protect your diary: never attach a Headmon JSON, CSV or PDF export, medical document, private photo, exact location or other health information to a public GitHub issue. Describe the behavior using invented example data instead.

Before reporting a problem

  1. Check the Headmon version and build under Settings → About Headmon.
  2. Restart Headmon and, if appropriate, restart the device.
  3. Create a private JSON backup before reinstalling, resetting data or testing an import.
  4. Note the device model, operating-system version and the exact steps that caused the problem.
  5. Remove or replace all real diary details before sharing a screenshot.

Data recovery and migration

Headmon has no server copy of your diary and the developer cannot recover deleted local data. Use the app’s JSON export or optional automatic backup to keep a portable copy. JSON is also the supported way to move diary data between Android and iOS. Keep backups private: they can contain sensitive health information.

Medical notice

Headmon is a personal diary and pattern-viewing tool. It does not diagnose, treat or prevent a medical condition and is not a replacement for professional care. Contact local emergency services for urgent medical concerns.
